# Contexte du projet AEGIS-Techsud

Le projet AEGIS-Techsud porte sur l'audit et le durcissement d'une VM Debian 12 après l'identification de faiblesses de sécurité.

## Objectif

L'objectif est de vérifier automatiquement les principales mesures de sécurité et de conserver les éléments nécessaires à la démonstration du durcissement.

## Périmètre

- système Debian 12 ;
- accès SSH ;
- compte root ;
- pare-feu UFW ;
- permissions de répertoires ;
- mises à jour du système.
